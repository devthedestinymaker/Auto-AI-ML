# Data and AI Learning Lab

This workspace is a structured, hands-on path for learning data science, machine learning, generative AI, and agentic AI. It starts with programming and data foundations, then moves through modeling and modern AI systems, and finishes with integrated projects.

## Learning sequence

1. `00_Python_Fundamentals`: write and organize Python programs.
2. `01_SQL_and_Data_Engineering`: query, transform, and move data.
3. `02_Mathematics_and_Statistics`: build the quantitative foundations for analysis and modeling.
4. `03_Data_Analysis`: explore data and communicate evidence.
5. `04_Machine_Learning`: train and evaluate classical predictive models.
6. `05_Deep_Learning`: understand neural networks and their training process.
7. `06_Generative_AI`: work with language and other generative models.
8. `07_RAG_and_Vector_Databases`: ground AI responses in searchable knowledge.
9. `08_Agentic_AI_and_MCP`: build systems that use tools and structured context.
10. `09_End_to_End_Projects`: combine the skills in complete, documented projects.

Each topic folder has a guide with learning goals, important concepts, exercises, and project ideas. Work through the topics in order, keep notes and code alongside each guide, and revisit earlier material when a project exposes a gap. This lab is designed for steady practice: small experiments first, then increasingly complete systems.

## Getting started

Begin with `00_Python_Fundamentals/README.md`. Complete its exercises and project before moving on. Use public or synthetic data for practice, record assumptions and limitations, and document how to reproduce each result.
