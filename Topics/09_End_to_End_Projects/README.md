# End-to-End Projects

## What you will learn

Combine the earlier skills into complete projects that are understandable, reproducible, evaluated, and responsibly scoped.

## Important concepts

- Problem framing, intended users, and success criteria
- Data provenance, quality, and reproducibility
- Modular implementation, testing, and version control
- Evaluation, error analysis, limitations, and monitoring
- Documentation, privacy, security, and responsible release

## Practical exercises

- Write a one-page project brief with a question, constraints, and measurable outcomes.
- Build the smallest working version, then test each data and model stage.
- Ask another person to reproduce the result using only the project documentation.

## Suggested projects

- An end-to-end analytics project from raw data through a concise decision report.
- A deployed or locally runnable ML application with a baseline, evaluation, and monitoring plan.
- A bounded generative AI or RAG application with source checks and failure handling.

Choose a project small enough to finish. Explain what it cannot do as clearly as what it can do.
