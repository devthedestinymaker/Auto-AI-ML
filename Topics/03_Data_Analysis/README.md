# Data Analysis

## What you will learn

Turn raw datasets into defensible findings and communicate those findings clearly to other people.

## Important concepts

- Data inspection, cleaning, missing values, and outliers
- Exploratory data analysis and descriptive statistics
- Grouping, reshaping, and combining datasets
- Visualization choice, chart reading, and misleading encodings
- Questions, assumptions, uncertainty, and concise communication

## Practical exercises

- Profile a dataset and report its schema, quality issues, and limitations.
- Investigate a focused question using summaries and at least two suitable charts.
- Write a short evidence-based conclusion that distinguishes observations from assumptions.

## Suggested projects

- A public-dataset analysis with a reproducible notebook and short findings report.
- A compact dashboard for tracking a meaningful set of metrics over time.

Prefer clear questions and honest limitations over chart volume.
