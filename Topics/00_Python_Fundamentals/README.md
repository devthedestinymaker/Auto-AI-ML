# Python Fundamentals

## What you will learn

Build the Python skills needed to manipulate data, automate tasks, and later implement models and AI workflows.

## Important concepts

- Values, variables, built-in types, expressions, and control flow
- Functions, scope, modules, imports, and virtual environments
- Lists, dictionaries, sets, tuples, and comprehensions
- Files, exceptions, and basic debugging
- Iteration, testing, and readable program structure

## Practical exercises

- Write small programs that validate input and handle edge cases.
- Load a text or CSV file, summarize its contents, and write results to a new file.
- Split a script into functions and modules, then add tests for normal and unusual inputs.

## Suggested projects

- A command-line expense or habit tracker that saves data to a file.
- A log-file summarizer that reports counts and common patterns.

Start with short, readable programs. Move on when you can explain your code and test its behavior without relying on copy-paste.
