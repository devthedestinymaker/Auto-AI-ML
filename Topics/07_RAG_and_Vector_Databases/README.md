# RAG and Vector Databases

## What you will learn

Build retrieval-augmented generation workflows that find relevant source material and use it to ground responses.

## Important concepts

- Document parsing, chunking, metadata, and embeddings
- Vector similarity, indexes, and metadata filters
- Retrieval quality, ranking, and context construction
- Citations, grounding, and answer evaluation
- Data freshness, access control, and failure modes

## Practical exercises

- Split a small collection of documents and inspect chunk boundaries and metadata.
- Compare retrieval results for several queries and identify missed or irrelevant sources.
- Evaluate answers against source passages, including cases where the system should abstain.

## Suggested projects

- A question-answering prototype over a small, curated document set with citations.
- A retrieval evaluation report comparing chunking or ranking strategies.

Separate retrieval quality from answer quality so failures can be diagnosed at the right stage.
