# Machine Learning

## What you will learn

Formulate prediction problems, build baseline models, and evaluate whether their results are useful and reliable.

## Important concepts

- Supervised and unsupervised learning
- Train, validation, and test splits; cross-validation
- Regression, classification, clustering, and feature engineering
- Metrics, class imbalance, data leakage, and overfitting
- Baselines, pipelines, interpretability, and error analysis

## Practical exercises

- Establish a simple baseline before trying more complex models.
- Compare models using a metric suited to the problem and inspect errors by subgroup.
- Demonstrate how leakage or an inappropriate split can inflate evaluation results.

## Suggested projects

- A carefully evaluated classification or regression study using a public dataset.
- A reusable training and evaluation pipeline with documented assumptions.

Keep the test set separate until model and decision choices are complete.
