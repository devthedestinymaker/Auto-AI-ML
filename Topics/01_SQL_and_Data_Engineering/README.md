# SQL and Data Engineering

## What you will learn

Query relational data and understand the reliable movement and transformation of data between sources and useful tables.

## Important concepts

- Tables, keys, relationships, and database normalization
- `SELECT`, filtering, sorting, aggregation, joins, and subqueries
- Common table expressions and window functions
- Data types, constraints, transactions, and indexes
- ETL/ELT, data quality checks, and pipeline stages

## Practical exercises

- Query a small relational dataset and answer questions with joins and aggregates.
- Reconcile row counts and nulls before and after a transformation.
- Design tables for a simple business domain and document key constraints.

## Suggested projects

- A reproducible pipeline that loads raw CSV files, validates them, and produces clean analytical tables.
- A small reporting database with SQL queries for recurring metrics.

Focus on correctness and traceability before optimizing for scale.
