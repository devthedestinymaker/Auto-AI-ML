# Generative AI

## What you will learn

Understand how generative models produce outputs and how to use them thoughtfully in constrained applications.

## Important concepts

- Tokens, embeddings, language-model prediction, and context windows
- Prompt structure, sampling, and output variability
- Model limitations, hallucinations, bias, privacy, and evaluation
- Structured outputs, tool interfaces, and human review
- Cost, latency, and quality trade-offs

## Practical exercises

- Compare prompt variants on a fixed set of examples using explicit success criteria.
- Request structured output and validate it before using it downstream.
- Create a small evaluation set and categorize incorrect or unsupported responses.

## Suggested projects

- A source-grounded document summarizer with human review.
- A structured extraction workflow that validates fields and reports uncertainty.

Treat generated content as untrusted until checked, and avoid sending sensitive data to services without authorization.
